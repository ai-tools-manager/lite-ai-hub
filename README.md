# ai-tools-manager

## Концепция

**ai-tools-manager** — это централизованный хаб для управления библиотеками, которые служат интерфейсами для `function calling` в LLM-агентах.

## Принципы реализации

- **Среда исполнения**: Каждая библиотека развертывается и работает как независимый сервис в кластере Kubernetes.

- **Назначение библиотек**: Библиотеки предоставляют HTTP API, предназначенное для использования LLM-агентами в качестве `tools` (инструментов) для выполнения `function calling`.

- **Изолированные ресурсы**: При установке для каждой отдельной библиотеки создается свой собственный, изолированный набор ресурсов в Kubernetes:
    -   `Deployment` для управления подами приложения.
    -   `Service` для обеспечения сетевого доступа.
    -   `HTTPScaledObject` для определения правил масштабирования.

- **Масштабирование на основе трафика (Scale-to-Zero)**: `Deployment` каждой библиотеки автоматически масштабируется от 0 до N реплик. Этот процесс управляется **KEDA** и основан на количестве входящих HTTP-запросов к сервису.

- **Gateway**: В качестве Ingress-контроллера используется **Traefik**. Этот выбор обусловлен его простой интеграцией и поддержкой в легковесных дистрибутивах, таких как k3s.

## API docs

### /chat

#### POST /chat

Создает новый chat

Response:

```json
{
  "chat_id": 0
}
```

#### GET /chat/list

Получает список всех чатов

Response:

```json
{
  "chats": [
    {
      "chat_id": 0
    }
  ]
}
```

### /message

#### GET /message/{chat_id} (TODO: добавить пагинацию в будущем)

Получает список всех сообщений чата

Response:

```json
{
  "messages": [
    {
      "role": "assistant",
      "content": "example text"
    }
  ]
}
```

#### POST /message/{chat_id)

Отправлет сообщениие в чат

### /lib

#### GET /lib/list

Получение всех установленных библиотек

Response:

```json
[
  {
    "name": "example name",
    "description": "example description",
    "git_url": "http://example-link.com"
  }
]
```

#### POST /lib

Cкачивает библиотеку (сохрвняет в бд) и создает knative контейнер с service

Request:

```json
{
  "git_url": "http://example-link.com"
}
```

#### DELETE /lib/{lib_url}

Удвляет библиотеку, контейнер, service
